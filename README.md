# Detecção Inteligente de Doenças em Cana-de-Açúcar

Projeto de Iniciação Científica: **Integração de Técnicas de Aprendizado Profundo e Imagens Agrícolas para a Detecção Inteligente de Doenças em Cana-de-Açúcar**.

## Objetivo

Desenvolver modelos de visão computacional, baseados em YOLO e OpenCV, capazes de identificar a cana-de-açúcar e diagnosticar suas principais doenças a partir de imagens agrícolas.

## Etapa atual

Treinamento de um classificador que distingue cana-de-açúcar de outras plantas.

## Estrutura do projeto

- `configs/`: configurações dos experimentos
- `docs/`: documentação e diário de experimentos
- `scripts/`: pontos de entrada (treinar, avaliar, inferir)
- `src/cana/`: código-fonte do projeto
